# Contract changes

The register of every change that touches a shared contract or asks another partition for something (SPEC 19, MASTER-PLAN D-45). A partition never edits another partition's file: it adds a row here, the owning partition implements it on its own branch, and the row's status changes. Frozen Phase 1 contracts (MASTER-PLAN 9.2): `build --json` shape, `check --report` shape, `engine/tools/checks.schema.json`, pack contract v0, `schemas/stages.json`, `schemas/order.schema.json` 1.2, the `.claude/VENDORED.json` row shape, hook stdin/exit codes, `tools/partitions.json`.

Partition letters: A engine-core (+B in Phase 1), B engine-games, C qa-tools, D factory-tools, E claude-layer, F ci-gitops, G board-artifacts, H docs, T type-packs, P ppc. "X -> Y" reads "requested by X, implemented by Y".

Status values: `proposed` (awaiting the owner or the owning partition), `accepted (Phase 1 default)` (accepted under owner question 3's default "all accepted as written"; the owner may still strike a row), `done <commit>`, `rejected <reason>`, `superseded by <row|D-nn>`.

Seeded on 2026-10-06 with ECC-ADOPTION section 10.2 (notes 1-19) and MASTER-PLAN section 9.1 (notes 20-27). ECC's notes were written against SPEC 1.0; the "Reconciled" column records where the master plan's decisions changed a note's detail. The note text is the requirement; the reconciliation wins where they differ.
